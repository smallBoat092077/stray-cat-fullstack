# 流浪猫喂养小程序 - 前端

## 项目简介

流浪猫喂养微信小程序前端，基于原生小程序框架开发。

## 项目结构

```
stray-cat-miniapp/
├── app.js              # 应用入口
├── app.json            # 应用配置
├── app.wxss            # 全局样式
├── project.config.json # 项目配置
├── sitemap.json        # 站点地图
├── images/             # 图片资源
── utils/
│   └── api.js          # API 封装
└── pages/
    ├── index/          # 首页（地图）
    ├── cat/            # 猫咪模块
    │   ├── list        # 猫咪列表
    │   └── detail      # 猫咪详情
    ├── feeding/        # 投喂模块
    │   ├── list        # 投喂任务列表
    │   └── detail      # 投喂任务详情
    ├── adoption/       # 领养模块
    │   └── apply       # 领养申请
    └── profile/        # 个人中心
```

## 功能模块

### 首页（地图）
- 显示附近流浪猫位置
- 点击标记查看猫咪详情
- 底部展示附近猫咪卡片
- 上报流浪猫入口

### 猫咪模块
- 猫咪列表（支持状态筛选）
- 猫咪详情（图片、信息、健康状态）
- 打赏投喂入口
- 申请领养入口

### 投喂模块
- 投喂任务列表（待接单/已接单/已完成）
- 志愿者接单
- GPS打卡（距离校验）
- 上传打卡照片

### 领养模块
- 领养申请表单
- 住房、养猫经验等信息填写
- 提交审核

### 个人中心
- 用户信息展示
- 信用积分、投喂次数、服务时长
- 我的领养、投喂记录
- 志愿者申请
- 退出登录

## 快速开始

### 1. 安装微信开发者工具

下载地址: https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

### 2. 导入项目

1. 打开微信开发者工具
2. 选择「导入项目」
3. 项目目录选择 `stray-cat-miniapp`
4. AppID 填写你的小程序 AppID（或选择测试号）

### 3. 配置后端地址

编辑 `app.js` 中的 `baseUrl`：
```javascript
baseUrl: 'http://localhost:8080/api'  // 开发环境
// baseUrl: 'https://your-domain.com/api'  // 生产环境
```

### 4. 运行

点击「编译」即可预览

## 注意事项

1. **AppID**: 需要在 `project.config.json` 中配置真实的 AppID
2. **域名配置**: 生产环境需要在小程序后台配置合法域名
3. **位置权限**: 需要在小程序后台申请位置接口权限
4. **图片资源**: 需要添加 tabBar 图标和默认图片到 `images/` 目录
